Usage guidelines: https://lunchmoney.app/media-kit/#mk-guidelines
API terms: https://lunchmoney.app/terms-api

Run `python3 scripts/favicon.py` with ImageMagick installed to regenerate the
website and plugin icons. It removes only empty canvas, resizes proportionally
and adds clear space; it does not redraw or recolor the emblem. The favicon SVG
embeds the official raster artwork rather than tracing it.

This is an unofficial integration. Specific permission for plugin-icon use was
requested by email; no approval has been recorded here.
